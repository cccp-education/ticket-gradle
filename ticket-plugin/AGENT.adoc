= AGENT.adoc — Ticket Gradle

_Produit_ : Plugin Gradle de ticketing — GitHub Issues, Kanban, lien commit↔ticket
_Licence_ : Apache 2.0 (OSS)
_DAG_ : N4 — Plugin Gradle de gouvernance (consomme backlog Atlanta)
_Dépendance_ : agile-gradle (compileOnly, lecture backlog), langchain4j (LLM)

== Principe

Le plugin `ticket` transforme les US/EPICs du backlog (produit par Atlanta/agile-gradle)
en tickets actionnables sur GitHub Issues. Il maintient la **traçabilité bidirectionnelle**
entre backlog → ticket → commit → PR → merge → close.

Pipeline :
  Backlog (Atlanta) ──→ IA (LLM) ──→ GitHub Issues ──→ Kanban board ──→ commit link

Cas d'usage :
- Création de GitHub Issues depuis les US du story-mapping
- Kanban board To Do → In Progress → Review → Done
- Conventional commits auto-linkés aux tickets
- Auto-close quand la PR est mergée
- Rapport de traçabilité (quel commit ferme quel ticket)

== Loi de l'Économie d'Encre — Non-Répétition des Opérations Coûteuses

*PRINCIPE* : Une opération coûteuse (LLM, inférence cloud, enrichissement IA des GitHub Issues, création de tickets depuis le backlog) qui a déjà produit un résultat *valide et persistant* NE DOIT PAS être ré-exécutée sur la même entrée. Le résultat existant est la vérité ; le re-calcul est un gaspillage de tokens/crédits API/temps de build. L'IA n'est pas un générateur idempotent gratuit — c'est un service metered. Re-appeler le LLM pour enrichir un ticket déjà créé et validé sur GitHub : ce geste consomme du token sans produire de nouvelle connaissance. L'économie d'encre est la condition de viabilité économique du pipeline agentique MVP0.

*RÈGLE* :
. Avant toute opération coûteuse, **vérifier l'existence d'un artefact résultat** (GitHub Issue déjà créée, rapport de traçabilité, cache disque, ticket ID stocké).
. Si l'artefact existe et couvre l'entrée demandée → **réutiliser sans ré-invoquer**.
. Seul le **delta** (US nouvelles, backlog modifié, tickets manquants) doit être calculé — jamais l'ensemble.
. Ne **jamais écraser** un résultat validé par un re-calcul identique. L'écrasement est un symptôme de non-idempotence économique.
. L'invalidation est **explicite et ciblée** (US ajoutée, backlog édité), jamais globale par défaut.

*ANTI-PATTERNS SPÉCIFIQUES TICKET* :
. *Re-création systématique* : re-appeler le LLM pour créer des Issues déjà créées sur GitHub (doublons, spam API).
. *Re-enrichissement inconditionnel* : re-appeler le LLM sur tous les tickets parce qu'un seul US du backlog a été ajouté.
. *Cache-busting silencieux* : un `writeText()` qui écrase le rapport de traçabilité avant même d'avoir lu l'existant.

*PROTECTION* :
. Lecture avant écriture : vérifier l'existence de l'Issue sur GitHub (API lookup) avant de la créer ; stocker le mapping US→IssueNumber pour éviter les doublons.
. Delta tickets : ne créer que les US du backlog qui n'ont pas encore d'Issue correspondante (comparison backlog vs Issues existantes).
. `DisableCachingByDefault` ne dispense pas de l'idempotence applicative — Gradle ne sait pas ce qu'est un "ticket déjà créé", seul le domaine le sait.

*RÉFÉRENCE* : Source canonique — `bakery-gradle/bakery-plugin/AGENT.adoc` section "Non-Répétition des Opérations Coûteuses — Loi de l'Économie d'Encre" (Session 153). Portée transverse : 10 boroughs LLM metered. Potentiel 50-80% d'économie LLM sur le pipeline MVP0 complet.

== Tâches Principales

  ./gradlew ticketCreate          → créer des GitHub Issues depuis le backlog
  ./gradlew ticketBoard           → afficher le board Kanban (console/HTML)
  ./gradlew ticketLink            → lier les commits aux tickets (conventional commits)
  ./gradlew ticketReport          → rapport de traçabilité backlog→ticket→commit
  ./gradlew check                 → tests

== Stack

- Kotlin — DSL Gradle
- GitHub API (gh CLI wrapper ou kohsuke/github-api)
- langchain4j — enrichissement tickets IA
- agile-gradle — dépendance compileOnly, lecture backlog structuré
- Jackson — parsing backlog → issues

== Ne remplace PAS opencode

Le plugin automatise la création et le suivi des tickets.
Les décisions de priorisation restent humaines (via les ateliers Atlanta).
